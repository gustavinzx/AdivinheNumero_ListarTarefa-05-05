# Aulas Node.js e React

Repositório com os exercícios e atividades das aulas de Node.js e React.

---

## 📁 Estrutura

```
aulas-node-react/
├── atividade1/
│   └── adivinhe.js         # Jogo: adivinhe o número (Node.js)
├── atividade2/
│   ├── index.html          # Lista de tarefas
│   ├── style.css
│   └── script.js
└── aula-react/
    └── src/
        ├── App.js              # Componente principal
        ├── Calculator.jsx      # Componente da calculadora (com Custom Hook)
        ├── Calculator.css      # Estilo da calculadora
        ├── useCalculator.js    # Custom Hook
        └── components/
            └── Mensagem.js     # Componente de boas-vindas
```

---

## ▶️ Como rodar

### Atividade 1 — Adivinhe o Número
```bash
cd atividade1
node adivinhe.js
```

### Atividade 2 — Lista de Tarefas
Abra o arquivo `atividade2/index.html` direto no navegador.

### Aula React — Calculadora
```bash
npx create-react-app soma-de-dois-numeros
cd soma-de-dois-numeros
```
Copie os arquivos da pasta `aula-react/src/` para dentro da pasta `src/` do projeto criado e rode:
```bash
npm start
```
